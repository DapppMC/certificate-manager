# Gate 0: Discovery (greenfield and brownfield)
Never skip. No requirements or design before the brief is approved.

## Interview (compact, max 3 rounds for M/L, 1 for S)
Round 1: who uses it, the one painful job, what exists today, constraints
(budget, hardware, deadline), language of artifacts, executor models available.
Round 2: challenge. Premortem ("it failed in 3 months, why?"), devil's advocate,
smaller first version, what to cut.
Round 3: resolve open questions, including every `[LEGACY_ANOMALY]` from Gate -1.

## Output: Idea Brief (one page)
Problem, user, success measure, first version scope, explicit non-goals,
top 3 risks with evidence, open questions, size tier (S/M/L).

## Exit criteria
- User replied "approved" to the played-back brief.
- Non-goals list has at least 2 items.
- Every anomaly has a decision: keep / change / ask domain owner.
